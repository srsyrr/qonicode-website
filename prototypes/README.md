# Prototypes

Standalone HTML prototypes from the client intake work. They are kept here as options and are not part of the site. Open any file directly in a browser.

- `client-flow.html`: the first prototype. A landing page view with a mark-on-page tool, plus the 9-step client flow (free check, intake, plan, access, status, preview, publish, handoff, close).
- `fix-list.html`: named-section store wireframe with a Phone/Desktop switch, five reasons per part and a side fix list.
- `fix-picker.html`: the version that went to the site. Two wheels (part, problem) with a live price and a cart-style fix list.
