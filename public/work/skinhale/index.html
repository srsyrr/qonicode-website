Skinhale

01

Duplicate theme

All work went to a copy, “D1 Work”. The original theme was kept as “BASELINE (do not edit)” and never changed, and nothing was published.

02

Acceptance criteria

Before any code, each request got clear checks, so “done” means the same thing to both of us. Pick a request: steps 03 and 04 follow it.

Hours logged on this practice project, including learning and QA. CR-01 (settings only) was not timed.

CR-01 Brand settings, no code

Request Apply Skinhale's colours, heading font and button style with theme settings only.

  • Page background #FAF7F2 and body text #2B2622
  • Page and product titles use the new serif; body text stays Inter
  • “Add to cart”: terracotta fill, white text, pill shape
  • Every text and background pair measures at least 4.5:1 contrast
  • No theme code changed: only the settings file
  • Every changed setting listed old → new

CR-02 Product-card labels from tags

Request Products tagged badge:New show “New” as a small label on product cards. The labels can be switched off and restyled.

  • Daily Hand Cream shows one “New” label; a product without a badge tag shows no label and no empty markup
  • Body Wash shows “Limited edition run” and “New” without overlapping
  • A long label wraps inside the card at 360 px, no horizontal scroll
  • Switching “Show tag badges” off removes the labels; Sale and Sold out stay Passed in preview; editor check to do
  • Switching Filled ↔ Outline restyles every label without code Passed in preview; editor check to do
  • A card with labels still opens the right product
  • Theme Check: no new errors

CR-03 Product details from metafields

Request Show Key ingredients, Skin type and How to use on the product page when they are filled, and hide what is empty.

  • Heading and 3 rows with the right values on a product with all data
  • Only the filled row shows on a product with 1 field
  • Nothing from the block in the HTML on a product with no data
  • Changing a label in the editor changes the page, not the data Passed in preview; editor check to do
  • A long value wraps at 360 px, no horizontal scroll
  • Changing variant still updates price and image; add to cart adds that variant
  • Theme Check: no new errors

CR-04 “Show more” collection description

Request Show only the start of a long collection description with a “Show more” link, so shoppers see products first. The full text stays on the page for SEO.

  • “Shop all” shows the first 30 words + “…” and a centred “Show more” link
  • “Show more” opens the full text and reads “Show less”; clicking again closes it
  • Tab reaches the link; Enter or Space toggles it; focus outline visible
  • The full text is in the page source while collapsed
  • A short description shows in full with no link; an empty one has no markup
  • Switching it off, or changing words shown or labels, works from the editor Passed in preview; editor check to do
  • No horizontal scroll and no overlap at 360 px
  • Theme Check: no new errors
03

Tested at three widths

Drag the divider: the untouched theme on the left, my copy on the right. Across the store, 7 pages × 5 widths (360 to 1440 px) in Chromium, Edge and Firefox: 35 of 35 with no horizontal scroll and no broken images.

CR-01 Product page

Top of the product page: warm background, serif title, terracotta pill buttons.

Edge cases tested

  • Button hover text measured 4.22:1 at first; adding white to the palette lifted it to 4.51:1
  • One palette change re-colours the whole theme, not one page

CR-02 Collection page

Product cards: “Limited edition run” and “New” come from product tags.

Edge cases tested

  • 3 or more badge tags → only the first 2 show
  • Badge: in capitals works; an empty badge: and a notbadge: tag are ignored
  • Sale or Sold out plus a tag label → the theme badge comes first
  • The outline style was unreadable on a red photo; the label now has a background fill (5.10:1 on any photo)

CR-03 Product page

Same spot on the product page: the new “Product details” block from three metafields.

Edge cases tested

  • All 3 fields, 1 field and no fields tested on 3 different products
  • A 435-character value at 360 px wraps with no horizontal scroll
  • Variant change and add to cart still correct on a 12-variant product

CR-04 Collection page

Top of the collection page. The long description is test data; before, it was 6 words.

Edge cases tested

  • Long (119 words), short (11 words) and empty descriptions tested
  • Mouse, Enter and Space all toggle it
  • No JavaScript added: a native <details> element
04

Change log + how to edit

Which files changed and why, plus a short note so the store owner can keep editing it in the theme editor.

CR-01 Brand settings, no code

Change log

  • config/settings_data.json10 theme settings: 5 palette colours, the heading font, 4 primary-button settings. No code files.

How to edit

  1. Online Store → Themes → Customize → Theme settings → Colors, Typography or Buttons.
  2. Changing a palette colour updates every place that uses it.

CR-02 Product-card labels from tags

Change log

  • blocks/_product-card-gallery.liquidLoops over the product tags; a tag starting with badge: adds a label, at most 2
  • snippets/product-badges-styles.liquidLabels stack and wrap; Filled and Outline follow the brand button colour
  • snippets/card-gallery.liquidTag labels count as badges, so a card without an image keeps its title clear
  • config/settings_schema.json + locales“Show tag badges” and “Tag badge style” under Theme settings → Badges

How to edit

  1. Add a label: open the product → Tags → add badge:Your text (1 to 3 words).
  2. Remove it: delete the tag.
  3. All labels off, or another style: Customize → Theme settings → Badges.

CR-03 Product details from metafields

Change log

  • blocks/product-details-list.liquid (new)Reads the 3 metafields; one row per filled field; nothing at all when all are empty
  • templates/product.jsonBlock placed after the description; the merchant can move or hide it
  • locales/*.schema.json8 editor labels, in every language file so Theme Check passes

How to edit

  1. Fill the data: open the product → Metafields: Key ingredients (one per line), Skin type, How to use (one step per line).
  2. Change the labels: Customize → Products → Product details list.
  3. Move or hide the block: drag it in the left panel, or click the eye icon.

CR-04 “Show more” collection description

Change log

  • blocks/collection-description.liquid (new)Wraps the theme's own text block: first N words + “…” and a native toggle; otherwise renders exactly as before
  • templates/collection.jsonOnly the collection page uses the new block; other text on the site is untouched
  • config/settings_schema.json + localesTheme settings → Collection description: on/off, words shown (15–60), both link labels

How to edit

  1. Write the description: Products → Collections → open a collection → Description.
  2. Length, labels or off: Customize → Theme settings → Collection description.
  3. A description shorter than the word count shows in full, with no link.

Not tested yet

Safari, a real phone, and running the new settings in the Shopify theme editor (they pass in a local preview).
