Skinhale: before / after

  • Practice
  • Horizon 4.3.0
  • Liquid

A practice project on a Shopify development store, for a fictional skincare brand. Not client work: no real customers or sales. I took four change requests (CR) from a written brief and applied them to a copy of the Horizon theme. The untouched theme stayed as it was, and nothing was published.

Checked: 360 to 1440 px in Chromium, Edge and Firefox, against the acceptance criteria in the brief. Not yet: Safari, a real phone, and running the new settings in the Shopify theme editor.

The four change requests

  1. CR-01 Brand settings, no code

    Request
    Skinhale's colours, heading font and button style, from the theme editor only.
    Before → after
    White background, black text, sans-serif headings, black buttons → warm off-white, deep brown text, serif headings, terracotta pill buttons (10 theme settings).
    How to edit
    Theme settings → Colors / Typography / Buttons.

  2. CR-02 Product-card labels from tags

    Request
    A product tagged badge:New shows “New” on its card; labels can be switched off and restyled.
    Before → after
    Only Sale / Sold out badges → up to 2 labels from tags, after Sale / Sold out (e.g. “Limited edition run”, “New”).
    How to edit
    Add or remove a badge: tag on the product. On/off and Filled/Outline: Theme settings → Badges.

  3. CR-03 Product details from metafields

    Request
    Show Key ingredients, Skin type and How to use on the product page when filled; hide what is empty.
    Before → after
    Facts only inside the description → a “Product details” block below it, one row per filled field, nothing at all when all three are empty.
    How to edit
    Fill the three metafields on the product. Move or hide the block in the theme editor.

  4. CR-04 “Show more” collection description

    Request
    Show only the start of a long collection description, with the full text still on the page for SEO.
    Before → after
    Full description above the products → first 30 words + “Show more” / “Show less”, no JavaScript (the long text is test data).
    How to edit
    Theme settings → Collection description: words shown (15–60), link labels, on/off.
